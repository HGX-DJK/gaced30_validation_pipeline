# 📋 权威公信力参考数据目录 (Reference Ground Truth)

本目录专门用于存放用于比对验证的**权威公信力真值数据**。

### 支持的数据形式与组织方式：
1. **方式 A：全国/跨区域通用真值总表 (`.csv`)（最省心，强烈推荐）**：
   - 包含列：`lon`（经度）、`lat`（纬度）、`ref_label`（地面权威真值：0=非耕地, 1=耕地）。
   - **自动化特性**：程序会自动根据 `source_data` 中每一景 TIF 瓦片的地理外包范围（Bounding Box），自动截取并匹配落在该景范围内的真值样点，无需用户手动按瓦片拆分！
2. **方式 B：按瓦片命名的分景独立真值表 (`.csv`)**：
   - 文件名包含对应瓦片标识，例如对应 `Crop_114.0_35.0.tif` 的 `Crop_114.0_35.0_ref.csv`。
   - 包含列：`ref_label`（以及可选的 `map_label`、`lon`、`lat`）。
3. **方式 C：独立高分辨率基准图层 (`.tif`)**：
   - 如 10 米分辨率的 ESA WorldCover 耕地图层、欧空局 WorldCereal 10 米耕地图层、或高分亚米级人工判读图斑。
4. **方式 D：自动分层随机抽样 (Fallback)**：
   - 若某景在参考目录中未找到对应坐标的样点，系统会自动根据联合国手册 Cochran (1977) 抽样定理生成最优验证样方。

### 🔄 分类体系与像元值不一致时的处理机制（语义映射 / Cross-Walking）：

参考数据**完全不需要**在原始数值上与待验数据保持一模一样！根据《联合国农业统计遥感手册》第 8 章与第 2 章关于“分类系统语义对齐与重分类交叉映射（Semantic Harmonization & Cross-Walking）”的标准规范，系统内置了**全自动语义归一化引擎**：

| 参考真值数据来源 | 原始像元/属性编码 | 系统自动转换规则 |
| :--- | :--- | :--- |
| **标准二值 / GACED30** | `0`=非耕地, `1` 或 `10`=耕地 | `1` 或 `10` ➔ 耕地 (1)，`0` ➔ 非耕地 (0) |
| **ESA WorldCover 10米** | `40`=Cropland, `10`=Tree, `20`=Shrub, `30`=Grass, `50`=Built... | **自动识别**：`40` ➔ 耕地 (1)，其余类别 ➔ 非耕地 (0) |
| **ESRI 10米全球土地覆被** | `5`=Crops, `1`=Water, `2`=Trees, `7`=Built... | **自动识别**：`5` ➔ 耕地 (1)，其余类别 ➔ 非耕地 (0) |
| **中科院土地利用 (CNLUCC)** | `11`=水田, `12`=旱地, `2x`=林地, `3x`=草地, `5x`=建设用地... | **自动识别**：`11`、`12` ➔ 耕地 (1)，其余类别 ➔ 非耕地 (0) |
| **武汉大学 CLCD 30米** | `1`=Cropland, `2`=Forest, `3`=Shrub, `4`=Grass... | **自动识别**：`1` ➔ 耕地 (1)，其余类别 ➔ 非耕地 (0) |
| **地面调查实测文字描述** | 如 `"水田"`, `"旱地"`, `"玉米"`, `"大棚"`, `"林地"`, `"水体"` | **智能中文/英文分词**：农作物地类 ➔ 耕地 (1)，林草水建 ➔ 非耕地 (0) |

#### 手动指定自定义规则：
如果你的数据使用了特殊自定义编码，也可以在执行命令时手动指定：
```bash
# 示例 1：指定参考数据采用 ESA WorldCover 体系
python main.py --ref-preset esa_worldcover

# 示例 2：显式指定某些自定义编码为耕地 (如类别 40 和 41 为耕地)
python main.py --ref-crop-values "40,41"
```
